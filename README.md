# AI MALICE

Telegram-бот — ИИ-ассистент на Python. Отвечает на вопросы, помогает
с обучением и программированием, понимает изображения. Работает на
[aiogram](https://docs.aiogram.dev/) и модели `gemini-3.1-flash-lite`,
к которой обращается через OpenAI-совместимый API
[Provod.ai](https://provod.ai).

## Возможности

- **Текстовый чат.** Бот отвечает на языке пользователя.
- **Изображения.** Можно отправить фото или картинку файлом (JPEG, PNG,
  WebP, до 10 МБ) — с вопросом в подписи или без. Формат проверяется по
  содержимому файла. Картинки обрабатываются только в памяти и на диск
  не сохраняются.
- **Память диалога.** Бот помнит последние 20 сообщений (10 обменов
  вопрос-ответ). В группе у каждого участника своя история. После фото
  в истории остаётся текстовая пометка и ответ бота, поэтому можно
  задавать уточняющие вопросы о картинке без повторной отправки.
- **Команды:**
  - `/start` — приветствие;
  - `/reset` — очистить контекст текущего диалога.
- **Защита от перегрузки.** Не чаще одного запроса в 3 секунды и не
  больше 10 запросов в минуту на пользователя. Пока бот отвечает, новые
  сообщения того же пользователя не принимаются. Предупреждения о спаме
  отправляются не чаще раза в 3 секунды.
- **Надёжность.** Повторные апдейты Telegram пропускаются, вторая копия
  бота на том же компьютере не запустится. Запросы к ИИ повторяются при
  временных сбоях (до 2 повторов, таймаут ответа 45 с, подключения 10 с).
- **Длинные ответы** разбиваются на части по 4000 символов; если ответ
  обрезан ограничением длины ответа (1500 токенов), бот об этом
  предупреждает.
- **Приватность логов.** Тексты переписки и изображения в лог не
  записываются. В лог попадают служебные сведения: id чата,
  пользователя и сообщения, длина истории, счётчики токенов, формат и
  размер скачанного изображения, причина отклонения картинки, сведения
  об ошибках (с трассировкой), а также служебные записи библиотек
  aiogram и openai.

## Ограничения

- История хранится в оперативной памяти и **пропадает при перезапуске**.
- Бот работает, только пока запущен процесс `python main.py`.
- Обрабатываются только текст и изображения JPEG, PNG и WebP. Стикеры,
  голосовые, видео, другие файлы и остальные типы сообщений бот
  пропускает.
- Запросы к Provod.ai могут быть платными — проверь баланс и тарифы.

## Требования

- Python 3.13
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- API-ключ Provod.ai с доступом к модели `gemini-3.1-flash-lite`

## Установка и запуск (Windows)

Открой терминал в папке проекта и создай виртуальное окружение:

```bat
py -3.13 -m venv .venv
```

Активируй окружение. Команда зависит от терминала.

**Командная строка (CMD):**

```bat
.venv\Scripts\activate.bat
```

**PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

Если PowerShell сообщает, что выполнение сценариев отключено, разреши
запуск локальных скриптов для своей учётной записи и повтори активацию:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

После активации в начале строки появится `(.venv)`. Дальнейшие команды
одинаковы для CMD и PowerShell:

```bat
python -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

Впиши в `.env` свои значения:

```env
BOT_TOKEN=токен_от_BotFather
OPENAI_API_KEY=ключ_Provod.ai
```

Запуск:

```bat
python main.py
```

Остановка — `Ctrl+C` в окне терминала.

На macOS и Linux то же самое, но окружение активируется командой
`source .venv/bin/activate`, а `.env` копируется через `cp`.

## Проверка подключения к ИИ

Если бот не отвечает, запусти диагностику:

```bat
python check_model.py
```

Скрипт проверит ключ, покажет, есть ли модель бота в каталоге Provod.ai,
и при проблемах со связью пошагово проверит DNS, TCP и TLS. API-ключ в
выводе скрывается.

## Тесты

```bat
python -m pip install -r requirements-dev.txt
python -m pytest
```

Запускать нужно из папки проекта при активированном окружении. Тесты
не обращаются к сети и не используют настоящие токены: Telegram и
Provod.ai в них заменены имитацией.

## Структура

```text
main.py              бот: обработчики, память, лимиты, работа с ИИ
check_model.py       диагностика подключения к Provod.ai
tests/               тесты (pytest)
requirements.txt     зависимости бота
requirements-dev.txt зависимости для тестов
.env.example         образец настроек
```

## Безопасность

- Файл `.env` с токенами исключён из Git через `.gitignore`; в
  репозиторий попадает только `.env.example` с заглушками.
- Никогда не публикуй токен бота и API-ключ. Если они всё же попали в
  открытый репозиторий, сразу отзови их (в @BotFather — `/revoke`):
  удаление в следующем коммите не делает утёкший секрет безопасным.
